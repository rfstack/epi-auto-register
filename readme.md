# EPI Auto Register

Automação em Python para cadastro de EPIs por função a partir de uma planilha Excel.

## Tecnologias utilizadas

- Python
- Pandas
- PyAutoGUI
- Pyperclip
- Python-dotenv

## Funcionalidades

- Leitura de dados de uma planilha Excel
- Login automático em sistema web
- Busca de EPI por descrição
- Cadastro automático de funções relacionadas
- Cálculo automático do tempo de troca
- Uso de variáveis de ambiente para dados sensíveis
